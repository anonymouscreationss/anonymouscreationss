## About Me

I build autonomous systems that think, analyze, and act. My work sits at the intersection of **artificial intelligence**, **cybersecurity**, and **open-source intelligence** — turning raw data into actionable automation.

- **Primary Focus:** Multi-agent AI platforms, OSINT tooling, and security automation
- **Philosophy:** Open source everything that can be open sourced. Secure everything that can't.
- **Environment:** Terminal-first. Linux native. Cloud agnostic.
